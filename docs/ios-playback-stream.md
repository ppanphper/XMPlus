# iOS 无端口播放与听时任务

iOS 在线播放和边听边下使用 `AudioCache → 字节回调 → libmpv`，不创建本机 HTTP 服务。已下载文件仍以 `file://` 播放。Android 和桌面平台继续使用原来的 AudioProxy。

## 为什么采用字节回调

1.2.3+18 的用户日志包含播放器连接 `127.0.0.1:59400` 被拒绝。该证据能确认本机监听不可用，不能确认最初失效是由后台切换还是 LiveContainer 导致。

| 方案 | 对现有功能的影响 | 选择 |
| --- | --- | --- |
| 解码器直接打开远程 URL | 网络读取脱离 AudioCache，需要另行处理授权续期、缓存与下载复用 | 不作为本次实现 |
| 完整下载后播放文件 | 首播需要等待整集，改变边听边下行为 | 仅保留已有离线播放 |
| AVPlayer / AVAssetResourceLoader | 可无端口，但需替换播放器并重新实现状态、倍速、格式与中断处理 | 本次不更换播放器 |
| libmpv 自定义流 | 保留现有解码器及 AudioCache，只替换字节交付方式 | iOS 采用 |

## 数据与生命周期约定

- `IosAudioStream.mount` 创建随机 `xmpluscache://` 标识。标识只映射到已经通过账号与声音授权检查的 AudioCache，不携带远程地址、Cookie 或磁盘路径。
- `requireLocalAudio` 只接纳已挂载的自定义标识；不能直接把任意远程 URL 交给播放器。
- `XMPlusAudioStream` 为当前 mpv 实例注册 `mpv_stream_cb_add_ro`。使用随 media_kit 打包的 Mpv.framework，要求支持取消回调的 API。初始化失败会明确报错，不降级到任意远程直连。
- 解码线程同步等待字节；Flutter 主线程和 Dart isolate 继续异步工作。回调不调用 mpv API，不在主线程等待。单次请求最多 256 KiB，AudioCache 的短读取通常不超过 64 KiB。
- 读取支持文件末尾、未知总长和随机偏移。缓存版本变更后，已有流必须重新打开，避免混读两个版本。
- 停止、卸载或关闭会取消待完成读取；迟到的异步结果只引用独立的响应对象，不写入已经失效的解码缓冲区。原生等待有 120 秒上限。
- 原生读取或输出失败只上报一次；同一播放代的后续完成事件不再触发自动下一集；已知时长的声音须到达末尾附近才能接受完成标记。重试重新打开当前声音并保留进度。音频输出设备故障与音频读取错误分别提示。
- mpv 注册与播放器实例同寿命：播放器释放完成后才移除注册记录；同一实例重复 attach 不会重复注册。
- media_kit 的 `open` 使用临时播放列表，mpv 不接受其中的自定义协议。因此先清空播放列表，再用 `add` 的直接 loadfile 路径和 `playlist-pos` 打开。继续保留 `Media.start` 加载钩子，不开启 `load-unsafe-playlists`。
- AudioCache 原来的 iOS 网络传输、分块校验、续期、重试与下载租约继续生效。播放服务的实际播放进度和听时账本不因更换字节交付而变化。

## 听时结果约定

官方极速版先查询任务，再等待广告或浏览任务完成回调，最后申请并以服务端结果更新余额。XMPlus 尚未接入该任务完成 SDK，不能用空业务字段保证领到听时。

| 状态 | 行为 |
| --- | --- |
| 未完成任务 | 提示在喜马拉雅极速版完成任务；不发送领取 POST |
| 无任务 / 当日已完成 | 明确提示，不记录“结果未知” |
| 任务查询失败 | 可重新查询，不暂停领取状态 |
| 服务端明确拒绝 | 保留拒绝语义，不归为未知 |
| 已确认领取，余额查询失败 | 提示只查询余额；不重发领取请求 |
| 领取 POST 已调用，但缺少明确结果 | `reward_result_unknown`，暂停重复领取并要求核对 |

保留原有 `autoClaim` 配置键兼容资料，界面改为“自动检查听时”。定期查询余额与任务，不再循环申请补满 4 小时。旧版 `rewardPaused` 记录不自动清除，但不影响只读查询。未确认扣时账本不在本次改动中清除。

## 验证方式

- `dart analyze lib` 与 `tool/check_method_trace.dart`。
- 临时验证包覆盖任务状态、一次性 POST、成功后读失败、缓存字节、偏移、EOF、取消与挂载隔离；测试源按仓库约定不提交。
- iOS 原生验证覆盖回调注册、实际解码时间轴、拖动、倍速、暂停恢复、停止中断、迟到响应与释放。模拟器使用空音频输出，不能作为真机出声证明。
- 正式产物始终用 `tool/build_ios.sh` 从 `lib/main.dart` 构建，不把临时验证入口打入 IPA。LiveContainer、真机音频与真实账号权益由设备实测验收。
