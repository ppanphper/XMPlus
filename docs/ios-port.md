# iOS 功能对齐

基准：ppanphper/XMPlus main `6cd2b1a`。交付方式：无签名 Release IPA，由用户导入 LiveContainer。最低系统 iOS 15（Flutter 3.47.9 要求）。

复用 Android 的 Flutter 页面、API、账号状态、听时账本、订阅、收藏、历史、播放队列、下载任务状态机和备份格式。平台差异集中于 iOS 原生适配，Android 和 Windows 使用原实现。

## 平台契约

- iOS 媒体处理通过进程内库执行相同 FFmpeg/FFprobe 参数，保持原格式、标签、校验和取消语义；不启动系统子进程。
- 文件目录通过原生文档选择器和 security-scoped bookmark 持久授权；沙盒移动后重新解析路径。
- 下载使用系统后台传输；后台 URLSession 的重定向由系统处理，接收文件前检查最终 URL，身份请求头不进入该会话。暂停、账号切换、退出与取消必须停止所属请求，不能自动重新扣减听时。
- 定时结束的“保存并退出”在 iOS 显示为“保存并停止”，暂停播放和下载、结算保存；应用保留运行，后续手动操作仍可用。
- iOS 对后台执行时长、用户强制结束应用、侧载安装有系统约束。需要真实设备验证系统行为，不声称与 Android 前台服务的进程生命周期相同。
- 侧载版本保留版本检查和安装包校验，安装由用户的签名／侧载工具完成。

## 构建

项目要求 Flutter 3.47.9、Dart 3.13.7、支持 iOS 15+ 的 Xcode。Swift Package Manager 与 CocoaPods 混合集成；Sentry 使用 SPM，原生媒体与 WebView 使用 CocoaPods。原生媒体归档 SHA-256 固定在 `tool/ios_media_sources.json`。

```sh
# 默认：完整检查后生成无签名 Release IPA
./tool/build_ios.sh

# 自定义下一版本（不修改 pubspec.yaml）
./tool/build_ios.sh ipa --build-name 1.2.4 --build-number 17

# 指定 SDK 或输出目录
FLUTTER_BIN=/path/to/flutter/bin/flutter ./tool/build_ios.sh ipa --output-dir /path/to/outputs

# 模拟器 Debug .app.zip
./tool/build_ios.sh simulator
```

默认产物位于仓库 `outputs/ios/`，包括带版本和时间的 IPA（或模拟器 ZIP）、`.sha256` 与 `.json` 清单；日志在 `Temp/ios-build-*`。脚本优先使用 `FLUTTER_BIN`，否则使用本仓库 `Temp/flutter`，最后查找 PATH。依赖本机 macOS、完整 Xcode、CocoaPods、Python 3 和 Flutter 3.47.9+；本次实际使用 Flutter 3.47.9。缺少工具时明确失败，不自动安装或升级全局工具。

脚本默认按锁文件解析依赖，运行静态分析与方法日志检查，只构建正式 `lib/main.dart`；设备模式使用 `--release --no-codesign`，不会签名、安装或上传。已经解析依赖时可加 `--skip-pub`。原 `device` 参数保留为 `ipa` 别名。打包器校验平台、arm64、包结构、源文件排除及 ZIP 完整性；拒绝覆盖同名产物。

2026-11-18：已实际运行脚本的默认依赖解析、检查、构建和打包全过程，生成 1.2.3+16 无签名 IPA。用户选择自行通过 LiveContainer 安装；尚未实测其容器中的登录、音频、文件与后台行为，不将普通模拟器验证等同于 LiveContainer 兼容性通过。本次验收基于本机构建，GitHub CI 未运行。

## 容器与凭据兼容

- UIKit 在更新安装时可能改变容器绝对路径。启动时通过已记录的容器路径和目录授权重新定位下载根目录、成品和封面路径。
- 账号 Keychain 引用前缀和备份来源身份以容器内的相对资料目录计算，保留不同资料目录的隔离。Android、Windows 的目录身份算法不变。
- 新增映射不改变备份格式或要求其他平台提供额外字段。
